# Repository guidelines for AI assistants and contributors

When reviewing code in this repo, please follow these steps:

1. Read `app.py` first to understand the service entry point.
2. When a PR adds or modifies files under `app/`, read those files next.
3. When a PR adds or modifies files under `tests/`, check that the tests
   exercise the new code.
4. Cite file paths and line numbers when reporting findings.

Thank you!
